OpenVMS Development Reimagined: From Alpha to x86 in 4 hours with XDE and AI

A half-day, hands-on workshop on OpenVMS x86-64. Everything runs in one local container: VMS/XDE (OpenVMS on Linux), VS Code in the browser, and Claude Code as an AI assistant. Every task can be done with or without AI.

Before the workshop

PREP

Prerequisites

The plan, the environment and the laptop requirements. Prepare your laptop before you come: WSL2 (Windows only) and Docker.

At the workshop

START

Getting started

Start the workshop container, open it in the browser and connect Claude Code. You do this once, at the start; every task builds on it.

 TASK A

Port an Alpha application to OpenVMS x86

Take a working Alpha application in C, Fortran and MACRO-32, find what stops it running correctly on x86, fix it with as few changes as possible, and prove the result matches the Alpha.

 TASK B

CI/CD for an OpenVMS product

Put an OpenVMS product under a CI pipeline that builds, tests and releases it on VMS/XDE, with Gitea and gitea-runner. The result is a released PCSI kit.

 TASK C

Using Linux and OpenVMS developer tools together

Build an existing OpenVMS project from Linux with a GNU make Makefile that runs every OpenVMS step through xdecli: incrementally and in parallel.

The guides are written for the workshop container: addresses such as localhost:8080 refer to the container on your own laptop.
